## 测试配置

- 手动入口：**Actions → iKuuu WebMoniter 试运行 → Run workflow**。
- 复用已有 Repository Secret `ACCOUNTS`，格式为每行 `邮箱:密码`；无需手动提供 Cookie。
- 只运行 iKuuu 登录与签到，目标为 `https://ikuuu.top`；不启动其他任务或 Web 管理页面。
- 本地 CPU 模型识别文字点选和九宫格，单次登录最多 5 轮验证码，不调用付费验证码服务。
- 只有进入已认证用户页，随后收到服务端签到成功或今日已经签到确认，才返回成功状态。
- 运行日志与摘要中的账号和密码脱敏，不上传 Cookie、浏览器配置、截图或原始日志。
- 每次全新登录，不缓存账号会话。模型下载会核对固定 SHA-256。
- 单个账号执行最多 300 秒，整个 GitHub job 最多 12 分钟；失败会正确标红。

只有完整登录与签到验证通过后，才适合配置每天香港时间 07:10 的定时。

上游报告在公开演示页面测试了验证码识别；文字新样本整题正确率 14/20，九宫格 19/20，不能视为本账号或长期自动签到成功率。本仓库以每次 Actions 摘要中的实际服务端结果为准。

流程代码位于 `scripts/ikuuu_browser.py`，账号隔离与脱敏入口位于 `scripts/run_webmoniter.py`；仅复用固定提交中的本地识别和挑战图片辅助代码。上游源码在运行时按固定提交检出。

本地回归检查：`python -m unittest discover -s tests -v`。这些测试使用模拟浏览器响应，不代表真实网站登录或签到成功。
